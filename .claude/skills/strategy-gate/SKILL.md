# 策略驗證關卡

沒有通過這個關卡的規則，只能「記錄訊號」，不能下單（紙上交易也一樣）。這條規則來自 2026-10 的教訓：當沖 8 筆 0 勝，回測早就顯示沒有優勢卻仍上線。

## 步驟

1. **把回測逐筆結果輸出成 CSV**，欄位至少要有 `day`（YYYY-MM-DD）與 `net`（扣完成本的單筆報酬，%）。
   - 成本一律用零股實際成本：手續費 0.1425%×2、證交稅（當沖 0.3% 保守計、非當沖 0.3%）、買賣各 2 個 tick 滑價。
   - 現有回測可直接用：`daytrade_backtest.py`、`daytrade_pattern_scan.py`、`theme_backtest.py`（`swing()` 回傳的 DataFrame 有 `day`、`net`，`net` 是比例，加 `--ratio`）。
2. **執行關卡**：
   ```
   python .claude/skills/strategy-gate/scripts/gate_check.py <trades.csv> --name <策略名稱> [--ratio] [--universe "說明候選股怎麼選"]
   ```
3. 讀輸出：`PASS` 才能上線；`FAIL` 列出沒過的條件，照實告訴使用者，不要換個說法包裝。
4. 結果自動寫入 `output/strategy_gate/<策略名稱>.json`。引擎要開啟一條規則前先確認這個檔案是 PASS。

## 通過條件（寫死在 gate_check.py，改門檻要先問使用者）

- 樣本 ≥ 60 筆、≥ 20 個交易日。
- 依時間切成三段，**每一段**扣成本後的平均報酬都 > 0（防止只在某段行情有效）。
- 最後一段（樣本外）獲利因子 ≥ 1.2。
- 每日等權資金曲線的最大回落 ≥ −25%。
- 候選股不能是「事後挑選」：`--universe` 必須說明選股方式；若是用今天的名單回測過去（例如趨勢型態頁的 175 檔），標記為 `hindsight`，**最多只能得到 WATCH（觀察），不能 PASS**。

## 範例

- 「跌深反彈 09:30」：三段平均 −0.54%／+0.35%／…，第一段為負 → FAIL。
- 「題材波段 20 日」：三段為正但候選股是今天的題材清單 → WATCH，只能小額紙上前推，不能宣稱有效。
